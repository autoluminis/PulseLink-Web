02 / CONNECT

连接不同设备，读懂同一份数据。

已有 OPC UA 服务器直接连接。其他协议通过内置网关，进入统一监控链路。

OPC UA 客户端

从节点浏览，到持续订阅。

管理外部 OPC UA 连接，将节点绑定到业务设备与点位，持续获取数值、质量与时间戳。

  • 节点浏览、读取与订阅
  • 证书审批与连接诊断
  • 连接重连与订阅恢复
内置协议网关

统一点位，保留设备差异。

内置 Modbus TCP、Siemens S7、MQTT 驱动，将源点位映射为内部 OPC UA 变量。

  • 数据源与点位映射管理
  • 稳定 NodeId 与源时间
  • 质量与失鲜状态诊断

04 / RULES

定义异常，让通知有据可依。

设备规则判断“是否异常”，通知策略决定“通知谁、用什么通道、是否升级”。

规则定义

让条件明确，
让状态变化可追溯。

组合判断

数值、布尔、字符串比较；支持 AND / OR。

稳定性控制

触发与恢复防抖、恢复滞回、连续匹配次数。

数据时效

变化率与无数据超时，覆盖波动和停止更新的状态。

每一次通知，都有清晰的依据。

LICENSE YOUR DEPLOYMENT

按实际需求，升级正式授权。

点位、规则、历史保留时间及设备扩展额度以签名许可证为准。

01
从系统内进入购买

登录 PulseLink 后，打开“系统管理 → 许可证”，点击页面顶部的“购买许可证”。若按钮不可用，请由部署管理员先配置购买入口。

02
确认需求并完成购买

在购买入口说明部署规模、点位、规则、历史保留与设备扩展需求，确认授权范围、报价和交付方式。

03
激活或导入许可证

完成购买后，在同一许可证页面使用激活密钥在线激活；隔离网络场景则导入与当前设备 ID 匹配的受信任许可证包。
